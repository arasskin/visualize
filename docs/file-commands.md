Click a file node's label to open a command input at that position. Type a command such as `less`, `vim`, or `git log --`, then press Enter. A floating terminal pane opens at the click position, adjusted inward near screen edges to keep it visible, and runs the command with the file's absolute path appended as one quoted argument. The command uses the configured shell with login and interactive startup enabled, with the visualized project as its working directory. Output remains visible in the pane when the command exits.

Escape or clicking outside cancels the prompt. Dragging a label pans the graph. Folded nodes and external dependency nodes do not open a command prompt. Aliased labels retain their original file mapping, and file-backed declarations point to their source file. The server resolves the selected node and original relative filename against the current scan and rejects missing or mismatched files.

Run `node tools/file-command-checks.mjs` for the isolated Chrome check. It covers click placement, aliases, cancellation, non-file nodes, drag suppression, zoomed label hits, native command submission, floating-pane placement, and exact argument delivery for a filename containing spaces, quotes, shell punctuation, and Unicode. The default screenshot is `/tmp/visualize-file-command.png`. Backend tests cover shell quoting and stale or mismatched file selections.
