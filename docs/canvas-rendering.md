Graphviz still computes layout and returns SVG. The browser keeps that SVG hidden at its original size and reads its paths, transforms, labels, colors, and geometry when the graph or theme changes. `graph-canvas.js` compiles those primitives into Canvas 2D drawing commands and Path2D objects. The visible graph is a canvas; it is not a CSS-transformed live SVG or an SVG image loaded into the canvas.

A low-resolution overview covers the whole graph. A higher-resolution cache covers the visible area plus a margin. During navigation, the renderer moves and scales these cached pixels with `drawImage`, without querying SVG geometry. Zoom uses a zero-millisecond settle timer, with sharp redraws queued through `requestAnimationFrame` so pending paints are coalesced. This allows the detailed cache to refresh between zoom events. Dragging retains the cached image until release. Small pans reuse the existing detailed cache while its margin still covers the viewport. Areas revealed beyond it use the overview until the next sharp redraw.

The overview is limited to about four million pixels, and the detail cache and display canvas to about sixteen million pixels each, with additional dimension limits. This bounds pixel storage for large layouts and high zoom levels. Temporary softness while scaling is expected; the settled view is redrawn subject to those limits.

Edge hover uses Path2D stroke hit testing in graph coordinates. Search, node anchoring, and the search arrow use stored layout coordinates mapped through the current view. Selection outlines, hovered edges, the search arrow, and change flashes are separate canvas overlays. Fold hatching, cluster boundaries, theme colors, and the project's loaded fonts are retained. Font loading and theme changes rebuild the scene and its caches. Graph replacement releases the old renderer and its observers.

The renderer supports the SVG primitives generated by this project's Graphviz output: paths, ellipses, polygons, polylines, rectangles, lines, and positioned text. It is not a general SVG interpreter.

Browser regression checks:

```sh
node tools/canvas-checks.mjs /tmp/visualize-canvas.png
```

The checks use an isolated project and browser. They verify visible canvas pixels, navigation coordinates, no SVG mutations during gestures, no label drawing or SVG geometry queries during cached movement, search and arrow sizing, edge hit detection, graph replacement, Retina backing dimensions, theme changes, and native pointer dragging. They do not collect timing traces or establish a performance improvement.
